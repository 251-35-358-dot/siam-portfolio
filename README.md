# Md Siam Pk — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy

### Netlify (quickest)

1. Visit https://app.netlify.com/drop and sign in.
2. Drag the extracted `siam-portfolio` folder (the folder containing `index.html`) onto the deploy area.
3. Netlify will publish the site and provide a public URL.
4. Open the URL and test the page on desktop and mobile.

### GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and copy the provided website URL.
